# プロジェクト資料（docs/project）

[AGENTS.md](../../AGENTS.md) から参照される、**ソースコードからは読み取れないサイト固有の情報**をまとめたディレクトリ。実装の詳細（テンプレートの中身、SCSS、関数など）はソースコードを直接読む。

| ドキュメント | 内容 |
| --- | --- |
| [sitemap.md](./sitemap.md) | ページ構成・URL・スラッグ・ページ分類・カスタム投稿タイプ・タクソノミー |
| [site-info.md](./site-info.md) | サイト名・連絡先・SNS・ブランド用語など |

## 更新ルール

- ページ・投稿タイプ・タクソノミーを追加・変更したら、同じコミットで [sitemap.md](./sitemap.md) を更新する。
- 未確定の情報は推測で埋めず、`要確認` と書く。
- ソースコードを見れば分かること（テンプレートの構造、関数の引数など）はここに書かない。
